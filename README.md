# FPGA-Based Physical Unclonable Function (PUF) Fingerprint Generator

> Mini Project | Department of Electronics & Telecommunication Engineering

## Overview

This project aims to develop a hardware fingerprint generation system using a **Physical Unclonable Function (PUF)** implemented on an FPGA. The generated fingerprint is unique to every FPGA device due to inherent manufacturing process variations, making it suitable for secure device authentication and hardware security applications.

The project explores the complete workflow from PUF design and implementation to fingerprint generation, evaluation, and authentication.

---

## Objectives

- Design and implement a PUF architecture on FPGA.
- Generate unique hardware fingerprints.
- Evaluate reliability and uniqueness of generated fingerprints.
- Interface the FPGA with STM32 for challenge-response communication.
- Study the applicability of PUFs in secure authentication systems.
